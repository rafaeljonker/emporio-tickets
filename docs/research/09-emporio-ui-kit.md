# Research 09 — Empório UI kit (extracted from the Empório design-system source, read-only)

Key correction to 07/08: Empório "spruce" is the light wood tone #E9D8B8 used for cards (not green). Honey #C98A2B is brand/rule; terracotta #A54A29 primary; oxblood #9A2E24 destructive; moss #46602B success; walnut #3B2A1E text/rail; muted #6B5444; hairline #D8C29C; paper #FFFCF6 inputs/popovers.

Signatures: terracotta only on clickables; walnut rail + 3px honey rule (wordmark never on rail; avatar 40px + title on rail); cream canvas + paper grain .05; spruce cards no border/shadow; paper inputs; 44px pill buttons; walnut 2px focus outline offset 2px; Fraunces SOFT 100 WONK 0 once per screen; walnut customer bubbles / spruce agent bubbles; icon + word statuses; Lucide 1.75; tabular numbers. Never: blue/cool grey, pure black, gradients, emoji, ALL CAPS, sparkle/robot icons, spinners, texture behind small text.

Recipes: page column 42rem (forms 28rem); buttons 44px/600/16px, primary #A54A29 hover #93401F active scale .98; secondary 1px input border on spruce; ghost hover spruce; destructive oxblood; inputs 44px paper 1px #6B5444 border radius 8; labels 16/600 above; errors 14/600 oxblood + CircleAlert; dialog backdrop rgb(59 42 30/.4), panel paper radius 12 shadow-xl max 32rem, title Fraunces 20/600; badge pill 14/600 icon 16; chat bubbles radius 21.6px, agent spruce w/ avatar on last, customer walnut; toast (extrapolated) paper + border + shadow-lg + icon; skeleton spruce blocks no shimmer.

Assets: frontend/src/assets/wordmark.jpg (600×335, cream bg), avatar.jpg (96²), public/favicon.png (64²); hi-res concepts in .design/branding/emporio-da-musica/identity/assets/; reference mockups in .design/projects/emporio-chat/design/mockups/ (+ mockup.css); guidelines.html.
