6. Mobile and not found

On phones the rows stack, actions move to a menu button that is always visible, and "New ticket" becomes a sticky bar at the bottom. Two 404s following the GOV.UK "Page not found" pattern: plain title as the H1 and the tab title, no "404" jargon, no "oops" or puns, no red warning text, no blame, one way forward. Both return a real HTTP 404. The ticket one comes from the edit route's own not-found; any other URL gets the root one.
